# Альфа-Сигнал

MVP сервиса новостной аналитики для принятия бизнес-решений.

## Что делает прототип

- Позволяет выбрать профиль компании.
- Показывает приоритетные новостные сигналы для выбранного профиля.
- Отображает бизнес-интерпретацию: возможное влияние события, риски и возможности.
- Демонстрирует, как одна и та же новость может быть связана с разными бизнес-факторами.

## Запуск

1. Скачайте файлы проекта: `index.html`, `style.css`, `script.js`.
2. Сохраните их в одной папке.
3. Откройте `index.html` в современном браузере.

Для текущего демонстрационного прототипа сервер и установка зависимостей не требуются.

## Ограничения текущей версии

- Используются демонстрационные профили компаний, новости и подготовленные примеры интерпретаций.
- Реальное получение новостей, подключение языковой модели и автоматическая проверка источников пока не реализованы.
- Выводы показывают концепцию продукта и не являются финансовыми рекомендациями.

## Структура проекта

- `index.html` — структура интерфейса.
- `style.css` — оформление.
- `script.js` — логика интерфейса и демонстрационные данные.
